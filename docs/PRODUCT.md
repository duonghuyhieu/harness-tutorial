# Product — harness-tutorial

## Users and jobs

Developers and technical leads who use AI coding agents. Jobs: understand why capable agents still fail; learn the
harness-engineering principles that fix it; install and use harness-kit with confidence. Quality bar: every claim
sourced and tagged with its evidence type; the page still reads correctly with JavaScript off.

## Golden journeys

1. Newcomer: index → problems → principles → harness-kit → guide (install one-liner) → done.
2. Practitioner: guide → install → daily workflow → troubleshooting.
3. Skeptic: any number → its evidence tag → the citation → references.html → original source.

## Out of scope

No tracking or analytics, no backend, no comments, no marketing claims, no attack techniques (findings and defenses
only), no facts that are not in docs/CONTENT.md.
