HƯỚNG DẪN

Hướng dẫn sử dụng

Từ một dòng lệnh cài đặt tới quy trình hằng ngày và vòng lặp tự động. Cơ chế đằng sau từng lệnh được giải thích ở trang harness-kit. Mã nguồn: Dương Huy Hiếu, 2026.

Đo số liệu công bố SX báo cáo sản xuất MH minh họa SL suy luận

Cài đặt

Chạy một lệnh trong thư mục dự án rồi mở Claude Code; không cần bước nào khác. Yêu cầu: Python 3.10 trở lên có trên PATH. Chạy lại lệnh sẽ cập nhật kit và giữ các tệp bạn đã sửa Dương Huy Hiếu, 2026.

irm https://raw.githubusercontent.com/duonghuyhieu/harness-kit/main/install.ps1 | iex
curl -fsSL https://raw.githubusercontent.com/duonghuyhieu/harness-kit/main/install.sh | bash

Dùng được trong macOS, Linux và Git Bash.

npx github:duonghuyhieu/harness-kit
# hoặc
npm install -D github:duonghuyhieu/harness-kit

Cần Node ≥ 18 và Python ≥ 3.10. Với npm install -D, bước postinstall chỉ cài vào dự án ở lần đầu (khi chưa có .claude/harness-kit.json), và bỏ qua trong CI; nếu npm chặn install script, chạy npx github:duonghuyhieu/harness-kit.

Minh họa phiên cài đặt trên Windows MH:

irm https://raw.githubusercontent.com/duonghuyhieu/harness-kit/main/install.ps1 | iex Downloading harness-kit ... DONE — harness-kit 2.1.2 is installed and active

Cài những gì

  • Ở gốc dự án: AGENTS.md, CLAUDE.md, PROGRESS.md, feature_list.json, init.sh / init.ps1, thư mục docs/.
  • Runtime và cấu hình: scripts/harness.py, .harness/config.json, .harness/rules.json.
  • Lớp Claude Code trong .claude/: agents/, skills/hk-*/, hooks/harness_hook.py, output-styles/, settings.json và manifest harness-kit.json.

Không ghi đè tệp của bạn

Tệp xung đột được đưa vào .harness/proposals/; settings.json có sẵn được gộp từng mục.

Quy trình hằng ngày

  1. /hk-start — vào ca.
  2. /hk-plan — biến yêu cầu thành feature có lệnh kiểm chứng và phạm vi.
  3. /hk-implement — next, xây dựng trong phạm vi, try, hk-reviewer, verify.
  4. /hk-handoff — cập nhật PROGRESS.md, ghi quyết định, exit-check, commit.

Lệnh runtime tương đương cho mọi agent: python scripts/harness.py start, add, next, try <id>, verify <id>, handoff, exit-check.

Ví dụ một feature

Minh họa MH: thêm một feature kiểm chứng bằng pytest rồi đưa nó qua pass-gate.

python scripts/harness.py add --id F012 --behavior "POST /orders returns 201 and persists the order" --verify "pytest tests/test_orders.py -q" --scope "src/orders/*" "tests/test_orders.py"
python scripts/harness.py next --id F012
# hiện thực trong phạm vi
python scripts/harness.py try F012
# hk-reviewer kiểm độc lập
python scripts/harness.py verify F012   # PASS, bằng chứng được ghi lại

Trong dự án mới cài, danh sách feature đã có sẵn các feature nền của harness (H001…): làm cho lệnh setup/test chạy được, viết test đầu tiên… Lệnh next không kèm --id sẽ chọn chúng trước theo thứ tự ưu tiên; dùng next --id F012 để làm feature của bạn ngay.

Vòng lặp tự động

python scripts/harness.py loop --dry-run
python scripts/harness.py loop --max-features 3 --max-attempts 3 --max-total-usd 5 --model sonnet
python scripts/harness.py report

report in bảng kiểm đối chiếu lý thuyết; chỉ thêm --commit nếu bạn đã chấp thuận trước việc commit. Sáu trang nội dung của chính trang web này được dựng bằng vòng lặp ấy — xem hộp Cách trang này được xây dựng.

Cập nhật, gỡ cài đặt, doctor

  • Cập nhật — cách khuyến nghị: chạy lại lệnh cài đặt. Nếu đã cài bằng install.sh: python ~/.harness-kit/harness.py update .; trên Windows PowerShell: python "$HOME\.harness-kit\harness.py" update .; nếu cài bằng npm: chạy lại npx github:duonghuyhieu/harness-kit.
  • Gỡ: python ~/.harness-kit/harness.py uninstall . (PowerShell: python "$HOME\.harness-kit\harness.py" uninstall .).
  • Kiểm tra sức khỏe: python ~/.harness-kit/harness.py doctor . (PowerShell: python "$HOME\.harness-kit\harness.py" doctor .).

Xử lý sự cố

Hook không chạy

Chạy doctor: lệnh kiểm tra python cho hook và việc đăng ký hook.

“workspace has not been trusted”

Mở dự án một lần ở chế độ tương tác và chấp nhận trust. Sau đó các quy tắc allow có hiệu lực; hook và quy tắc deny vốn đã áp dụng.

Bị hỏi trước khi ghi ngoài phạm vi

Đây là thiết kế. Thêm tệp vào scope của feature hoặc tạo feature mới; hoặc đặt "scope_guard": "off".

Hook Stop chặn kết thúc

Sửa các vấn đề được liệt kê rồi chạy exit-check.

Lệnh test hoặc lint sai

Sửa mục commands trong .harness/config.json.

Tắt hook cho một phiên

Đặt biến môi trường HARNESS_HOOKS=off.

Cách trang này được xây dựng

Chính trang này dùng harness-kit

Mỗi trang là một feature có lệnh kiểm chứng (python tests/check_site.py --page <trang>), một phiên maker cho mỗi trang, một reviewer chỉ đọc và pass-gate. Kết quả: 6 feature (mỗi trang một feature), sau các sửa lỗi đều đạt ngay lần thử đầu; 7 lần chạy dựng 6 trang tốn khoảng 4,26 USD, lần chạy F008 cập nhật hai trang thêm khoảng 0,39 USD, còn phần tinh chỉnh giao diện cuối làm ngoài vòng lặp; vòng lặp làm lộ hai lỗi của harness-kit (đã sửa, có kiểm thử hồi quy) và một vấn đề của trình kiểm tra trang này — chi tiết ở trang harness-kit. Báo cáo của lần chạy nằm trong .harness/runs/ (cục bộ) SX Dương Huy Hiếu, 2026.
